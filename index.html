Aviso

Acceso de Administrador

🗄️ Base de datos

Con la base de datos: el stock y los precios cambian al instante para tus clientes, cada pedido queda guardado y llevas el registro de tus clientes.

1. Conectar tu proyecto de Firebase

Pega la configuración web de Firebase (el bloque const firebaseConfig = { … }).

2. Entrar como administrador

Primero completa el paso 1.

3. Reglas de seguridad

Cópialas en Firebase → Firestore Database → Reglas y toca Publicar. Así solo tú puedes ver pedidos y cambiar precios.

4. Aviso por correo (Google Apps Script)

Pega la dirección de tu aplicación web de Apps Script (termina en /exec). Cada pedido nuevo te llegará por correo.

Comprar es fácil: eliges tus sets en la web, nos mandas el pedido por WhatsApp y te los entregamos en Dota 2. Así funciona, paso a paso:

  1. 1
    🛒

    Elige tus sets

    Entra a Sets Caché y toca 🛒 Agregar en cada set que quieras. Puedes agregar varios.

    🎁 3 sets: −10% · 6 o más: −15%
  2. 2
    🧾

    Revisa tu carrito

    Toca la barra del carrito que aparece abajo. Ahí ves la foto de cada set, la cantidad y el total con descuento.

  3. 3
    💬

    Envía tu pedido por WhatsApp

    Toca Enviar pedido por WhatsApp. Verás tus sets y se abrirá el chat de LitleJacob con la lista y el total ya escritos. Solo envía el mensaje.

  4. 4
    🎮

    Paga y recibe

    Te confirmamos disponibilidad, pagas con Yape, Plin, PayPal o Binance y te entregamos los sets en Dota 2.

Aviso

Acceso de Administrador

🗄️ Base de datos

Con la base de datos: el stock y los precios cambian al instante para tus clientes, cada pedido queda guardado y llevas el registro de tus clientes.

1. Conectar tu proyecto de Firebase

Pega la configuración web de Firebase (el bloque const firebaseConfig = { … }).

2. Entrar como administrador

Primero completa el paso 1.

3. Reglas de seguridad

Cópialas en Firebase → Firestore Database → Reglas y toca Publicar. Así solo tú puedes ver pedidos y cambiar precios.

📋 Pedidos y clientes

Publicar en GitHub

Se configura una sola vez. Los datos se guardan solo en este navegador; el token nunca se sube a la página.

Editar set

La foto se ajusta sola al tamaño de la tarjeta.
El estilo 1 es la foto principal. Si el set tiene más estilos, sube aquí una foto por cada uno.
Cuántos tienes de este set (solo lo ves tú). Déjalo vacío si no llevas control. Con 0 se marca como AGOTADO.

Gestionar cofres

Escribe el nombre de cada cofre y toca su imagen para ponerle foto. Usa ▲▼ para cambiar el orden en el catálogo.
